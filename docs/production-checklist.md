# Production integration work

This local preview does not process actual transport orders. Before public use:

1. Confirm the missing master specification, launch scope, service regions, commercial terms and support process.
2. Add customer, carrier, driver and administrator authentication, server-side role authorization, assignment rules, session protection and account recovery.
3. Replace the local single-process JSON store with a transactional database, migrations, backups, concurrency protection and audit records.
4. Establish identity, vehicle, insurance and operating-document checks with explicit verification states and expiry handling.
5. Integrate an approved payment provider, signed webhook validation, idempotency, refunds, disputes and reconciliation.
6. Add actual carrier availability, dated journeys, route/time compatibility, quote negotiation, cancellations and confirmed rate/fee policies.
7. Add licensed maps, authorized location collection, driver consent, retention, stale-feed handling and shipment access controls.
8. Add conversation membership enforcement, moderation/reporting, notifications and attachment handling where required.
9. Define delivery proof, recipient authorization, claims and exception workflows.
10. Complete production security, accessibility, device performance and end-to-end integration validation.

The 3D asset is an original lightweight concept; a photorealistic optimized GLB has not been commissioned. The hero uses original illustrative bitmap artwork for its fast static presentation.
